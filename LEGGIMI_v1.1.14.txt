ARCHIVIO PRO v1.1.14 - CRONOLOGIA RICERCHE

INSTALLAZIONE
1. PRIMA: Supabase > SQL Editor > incollare ed eseguire
   INSTALLAZIONE_CRONOLOGIA_RICERCHE_v1.1.14.sql
2. POI: pubblicare index.html sul repository GitHub come nelle precedenti versioni.
3. Effettuare login, cercare una sentenza dalla Scrivania premendo "Cerca",
   quindi controllare la sezione "Cronologia ricerche · ultime 50".
4. Nella sezione Fascicoli, le ricerche sono registrate dopo 1,4 secondi
   senza ulteriori modifiche al testo; non ogni lettera digitata.
5. Il comando "Ripeti" rilancia la ricerca scelta.

PRIVACY E PERMESSI
- Utenti autenticati: visualizzano le proprie ricerche.
- Vista generale per amministratore: necessita del ruolo 'admin' assegnato
  nel campo app_metadata di Supabase Auth, non solo della tabella 'utenti'.
  Senza tale configurazione l'amministratore vede le proprie ricerche.
- L'app salva le nuove ricerche, non quelle pregresse.
- Le ultime 50 sono limite di visualizzazione; il DB non elimina i dati
  automaticamente. Definire tempi di conservazione secondo norme interne.
- Le policy non consentono a utenti del sito di alterare o cancellare i log.
- La cronologia è operativa solo dopo aver eseguito lo script SQL.
